🚀 快速安装

几步即可开始使用

1

下载安装包

从 GitHub Releases 下载适合您系统的版本

前往下载
2

运行安装程序

Windows 用户运行 .exe 安装程序，Linux 用户使用 apt 安装

sudo apt install ./humanaize2_2.2.3_amd64.deb
3

启动应用

Windows 从开始菜单启动，Linux 在终端运行 humanaize2
