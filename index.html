Quick Installation

Add this repository to your system and install Humanaize 2.0:

echo 'deb [trusted=yes] https://a113nwu.github.io/Humanaize2-Project/apt-repo stable main' | sudo tee /etc/apt/sources.list.d/humanaize2.list
sudo apt update
sudo apt install humanaize2

Manual Download

Download and install the Debian package directly:

# For amd64
wget https://a113nwu.github.io/Humanaize2-Project/apt-repo/dists/stable/main/binary-amd64/humanaize2_2.2.0_amd64.deb
sudo dpkg -i humanaize2_2.2.0_amd64.deb
sudo apt install -f

Getting Started

After installation, launch Humanaize 2.0:

humanaize2

humanaize2-cli
