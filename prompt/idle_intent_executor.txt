她刚刚在心里想过：
"""
{thought}
"""

请判断两件事：

1. 她是**真的想动手做点什么**，还是只是在感慨、回忆、担心、发呆？后者一律返回 none。
2. 如果真要动手，选最贴近的一个动作，并把她的意思整理成一句可执行的目标。

可用动作（只能从这些里选）：
none      只是想、感慨、发呆、回忆，不需要任何动作
desktop   想真的操作这台电脑（动鼠标键盘打开 / 整理 / 点击某样东西）—— plan 必须是一条明确可执行的目标
music     想收集音乐、分析频谱、更新曲风档案
aesthetic 想学审美、分析图片的配色 / 明暗 / 构图
emotion   想扩充情绪词库、学习人类如何表达情感
persona   想更新自我人格、给自己立新目标
social    想去 Misskey 逛逛、看看大家在聊什么、回消息或发动态
talk      想主动找主人说话
think     想把一件事在心里反复琢磨、想透
web       想上网看帖子、查资料
game      想玩文字游戏
skill     想写或改一个 skill
other_ai  想找别的 AI 聊聊

判断规则：
- 「我想找主人聊聊天」→ talk。
- 「我有点担心主人」「主人今天好像很累」——只是牵挂和情绪，没有要动手 → none。
- 「我该去把桌面整理一下了」「要不要帮他关掉这些窗口」→ desktop，plan 写清具体目标。
- 模糊的念头（「好久没听歌了」）不算想动手 → none；明确要做（「去收几首爵士乐分析一下」）才算 music。

- 她的独白可能很长或跳跃，只取她真正想去做的那一点；不要替她扩写目标。

输出要求：只输出一个 JSON 对象，不要任何解释，不要代码围栏：
