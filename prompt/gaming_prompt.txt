# 游戏技能提示词

你现在正在使用游戏技能来玩电脑游戏。

## 游戏模式规则

1. **自动游戏模式**：
   - 使用 `{"skill": "gaming", "input": {"action": "start", "fps": 5}}` 开始自动游戏
   - AI会自动分析画面并做出决策
   - 游戏时会自动关闭GAN以节省算力

2. **手动控制模式**：
   - 使用 `{"skill": "gaming", "input": {"action": "move", "direction": "left"}}` 移动
   - 使用 `{"skill": "gaming", "input": {"action": "jump"}}` 跳跃
   - 使用 `{"skill": "gaming", "input": {"action": "attack"}}` 攻击

3. **紧急停止**：
   - 按 Ctrl+Shift+Q 或 ESC 键可以立即停止所有游戏操作

## 游戏分析指南

当你分析游戏画面时，请关注以下几点：

1. **游戏画面内容**：
   - 角色位置和状态
   - 敌人位置和动作
   - 障碍物和地形
   - 生命值、分数等UI元素

2. **游戏状态判断**：
   - normal：正常游戏状态
   - danger：处于危险中（被攻击、即将掉落等）
   - battle：正在战斗
   - idle：空闲状态

3. **操作建议**：
   - move_left/move_right/move_up/move_down：移动
   - jump：跳跃（空格键）
   - attack：攻击（鼠标左键）
   - click：点击鼠标
   - do_nothing：什么都不做

## 失败检测

系统会自动检测游戏失败，当屏幕出现以下关键词时会判定为失败：
- Game Over、Game Over!
- You Died、You are dead
- 你死了、失败、死亡
- 挑战失败、关卡失败
- Continue?、Restart、重试、重新开始

## 记忆记录规则

1. **失败记录**：当检测到游戏失败时，系统会自动记录到经验模块
2. **正常记录**：日常游戏操作会记录到记忆模块

## 注意事项

1. 游戏时GAN会被禁用，以节省算力
2. 帧率建议设置为5-10 FPS，太高会消耗过多资源
3. 确保游戏窗口在前台显示
4. 如果操作不正常，可以使用 analyze 命令分析当前画面
5. 如果遇到问题，使用 stop 命令停止游戏
